# Kits

One image per shirt, PNG or JPG, named:

    <season>-<type>.png            e.g. 1998-99-home.png, 2007-08-third.png, 1993-94-gk-home.png

- season: the first year and the two-digit second year, hyphenated (1998-99, 1999-00, 2026-27)
- type: home, away, third, gk-home, gk-away, gk-third (add -alt for a second version in the same season, e.g. 1995-96-away-alt.png for the grey/blue-white change)
- Keep the shirt roughly centred with a transparent or plain background; any size — the site resizes.

A spreadsheet or kits.json alongside the images carries the details the site shows (manufacturer, sponsor, seasons worn, notable matches, players); the shirt museum reads from that.
